# Team-task
L'objectif de ce projet est de concevoir et de développer une application  Web  permettant d'optimiser le suivi des tâches, de gérer la charge de travail et d'assurer une communication fluide au sein d'une équipe pluridisciplinaire. L'application intègrera également des fonctionnalités de suivi d'activité technique grâce aux webhooks Git.
