# Team Task — Back-office

Prototype haute fidélité d'un back-office de gestion de projets, construit avec React 19, TypeScript, Vite et Tailwind CSS v4.

## Démarrage

```bash
npm install
npm run dev
```

Ouvrez ensuite http://localhost:5173

## Connexion

Aucun backend n'est requis : les données sont mockées en mémoire. Sur l'écran de connexion, utilisez un des 3 boutons de connexion rapide (Admin / Chef de projet / Utilisateur), ou saisissez l'un de ces emails avec n'importe quel mot de passe :

- `camille.beranger@teamtask.io` — Administrateur
- `thomas.lefebvre@teamtask.io` — Chef de projet
- `antoine.girard@teamtask.io` — Utilisateur

## Build de production

```bash
npm run build
npm run preview
```

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4 (@tailwindcss/vite)
- lucide-react (icônes)
- react-router (navigation)
- React Context API (état global)
